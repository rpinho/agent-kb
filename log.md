# Log

Append-only chronological record of ingests, queries, and edits. Newest at the bottom. This file is set to `merge=union` in `.gitattributes` so concurrent sessions never conflict on it.

Format: one bullet per meaningful change, dated `YYYY-MM-DD`, saying what happened and where it landed.

---

- **YYYY-MM-DD** — KB initialized from the agent-kb scaffold.

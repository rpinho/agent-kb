# Digest daily items — RECURRING, not one-shot

**Difference from `digest-pins.md`:** pins are one-shot (include once, tick, done).
**These recur EVERY run until the state recorded here says otherwise.**

**⛔ Set a hard line cap and honour it.** A recurring block that grows the digest has failed its
purpose — it is a reminder, not a section.

---

## 1. <Drill / spaced-repetition block>

**The user drives the list**: they flip rows to `known` and add new ones. Never re-add a `known` row.

## 2. <Streak tracker>
**Rule: silence = did not happen.** Update `LAST DONE` only when the user reports it.

```
LAST DONE:  (never)
STREAK:     0
DUE DAYS:   Mon / Wed / Fri
```

**Print ONE line, and only on a due day or after a miss. Otherwise print nothing.**
